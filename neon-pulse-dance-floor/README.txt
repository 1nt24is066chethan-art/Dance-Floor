Neon Pulse - Virtual Dance Floor

Run in VS Code:
1. Unzip this folder and open it in VS Code (File > Open Folder).
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click dance-floor.html > "Open with Live Server".
4. Click "Join the party" (browsers block audio until you click).

Needs internet for the Three.js CDN and the font.
Controls: WASD move, drag to orbit, scroll to zoom, 1-9 and 0 dance, Enter chat.
